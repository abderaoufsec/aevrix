Welcome to Aevrix

Aevrix is a Linux-first/C++20 educational HTTP/1.1 web server.

This page is being served statically from the document root.

Current Features (Phase 6)

  • Static file serving
  • Path validation and security
  • MIME type detection
  • GET and HEAD support
  • Proper error responses (404, 403, 405)

Implementation Details

Built with C++20, RAII resource management, and RFC 9112 compliance.
